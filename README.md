# ExpiryDesk

ExpiryDesk is a productivity application for tracking product expiry dates,
reminders, and inventory information.

## What problem it solves

The project helps individuals and small businesses avoid expired products
by organizing expiry dates and sending reminders.

## Target users

- Small businesses
- Retail shop owners
- Individual users
- Inventory managers
